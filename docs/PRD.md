# Dither Studio PRD

## 输入与画布

### 输入类型

*   输入格式：图片（png/jpg/webp/gif 静帧/heic）与视频（mp4/webm/mov/gif 动图）。UI上不用展示说明
    
*   多媒体坑位：默认1个多媒体坑位，在全局设置中可切换为4个多媒体坑位，也就是说可以同时传4个图片/视频，且同时预览4个多媒体的dither 效果
    

### 适配方式

*   多媒体在画布内的放置：cover / contain / fill / 原尺寸，这个选项可以折叠起来，不用露出。默认 contain
    

### 画布与输出尺寸

*   画布：画布默认1000\*600px，视图支持10%、25%、50%、100%显示，默认10%
    
*   输出的最终分辨率（宽×高），独立于原图。用于社媒尺寸、印刷尺寸。
    

## 界面组织（左面板）

参数面板自上而下三层，顺序固定：

1.  **预设模块**：预设卡片、起名保存、当前方案状态。它改的是全部参数，所以常驻最上方，不从属于任何一节。
    
2.  **参数分节**：基础 / 影调 / 颜色 / 网格 / 特效 / 画布。不用 tab——整栏一列、每节可折叠，默认只展开「基础」，收起的节在标题右侧显示当前值摘要。
    
3.  每节内部：一句说明 + 控件网格，低频参数收进「更多参数」折叠。
    

其中「**基础**」= 算法 + 像素化：算法族、当前族的算法、颜色模式、像素尺寸、降采样这一排（原本浮在 tab 之上的快捷参数）整排并入，后面接当前算法族自己的参数，再接网格偏移等低频项。这两件事回答的是同一个问题——一个抖动点长什么样、有多大。布局细节见 `docs/DESIGN.md` §3.1。

## 参数解读（Param Help）

*   每一个参数都能解释自己：鼠标停在参数标签上，弹出浮层讲清「这是什么 / 各个值什么意思 / 什么时候选它」。
    
*   选项很多的下拉（算法、调色板），属性浮层只讲整体怎么挑，逐个值的解读挂在下拉展开后的选项行上。
    
*   目标是新用户不看文档也敢动每一个滑块，老用户不必记住六十多个算法的差别。
    
*   文案是产品的一部分：写作规范与维护方式见 `docs/PARAM_HELP.md`，交互与视觉见 `docs/DESIGN.md` §3.8。
    

## 像素化 / 颗粒（Pixelation）

> 界面位置：「基础」分节。

*   像素尺寸：降采样倍率，决定颗粒粗细。1–64，默认 2–4（按输入分辨率自适应）
    
*   降低采样方法：缩小时用 box 平均 / 双线性 / Lanczos / 最近邻
    
*   网格对齐 / 偏移：像素网格相对原图的起始偏移（x, y）
    

## 影调与预处理（Tone & Pre-processing）

*   自动调整：根据dither art的特点，自动调整下方的各个参数，开关
    
*   亮度调整
    
*   对比度调整
    
*   中间调 / 高光 / 阴影调整
    
*   饱和度调整
    
*   灰度转换公式：亮度 = BT.601 / BT.709 / 平均值 / 单通道（R/G/B）/ 最大值。默认 BT.709（线性空间）
    
*   模糊：抖动前高斯模糊，压制高频细节让颗粒更"干净"。0–100 px，默认 0
    
*   锐化：与模糊相反，增强边缘，让 1-bit 输出保留结构。
    
*   去噪：面向照片的平滑滤镜
    
*   噪点：增加噪点，可选择各种类型的噪点。
    
*   边缘描边（Outline）：抖动前提取边缘叠成线条
    
*   反相：输入亮度反转。所有竞品都有。
    
*   阈值：给量化前的亮度加固定偏置，用来补偿 Bayer 整体偏亮的 bias，也是 1-bit 模式下最重要的创意滑块。

## 颜色与调色板（Color & Palette）

### 颜色模式

*   沿用彩色化调研的四条路线：Palette（A）、Tint（B）、Channels（C）、Accent 叠加层（D）。
    
*   颜色模式：单色（1-bit 黑白）/ 灰阶 / Tint（双色 / 色带映射）/ Palette（真彩量化）/ Channels（RGB 或 CMYK 分通道）。Dither Garden 叫 Monochrome / Duotone / Tritone / RGB；fuegocoding 叫 Duotone / Grayscale / Custom Palette / Original。默认 Tint（黑白双色，即 1-bit）
    
*   颜色深度（灰阶级数） ：量化级数 / 调色板色数。灰阶模式下 2–16 级；Palette 模式下 = 调色板色数。
    
*   深度 / 色数错配：先按 N 级亮度抖动，再映射到 M 色调色板，N ≠ M 时产生 color glitch。开关
    

### 调色板

*   预设调色板：Game Boy（原版/Pocket）、CGA 0/1、EGA、C64、ZX Spectrum、NES、PICO-8、DB16/DB32、Apple II、Mac 1-bit、Web Safe、灰阶 4/8/16；
    

### Tint / 色带映射（Tint 模式专属）

*   暗色 / 亮色：双色调的两个颜色选择器。
    
*   色带（gradient map）：N 级灰 → N 色 ramp，可加中间色站点。
    

### Accent 强调色层（叠加层）

*   开关 + 强调色板：1–6 色，每色带权重。
    
*   密度：被替换像素比例。
    
*   放置规则：随机 / 蓝噪声 / 仅某灰阶档 / 误差溢出 / 边缘。
    
*   目标范围：仅前景 / 仅背景 / 全部。
    
*   最小间距 / 连锁概率 / 种子：防扎堆、偶发短线、复现。
    

## 后处理特效（Effects，可堆叠）

*   扫描线 / CRT：横向暗线 + 可选桶形畸变、荧光点。
    
*   胶片颗粒：抖动后叠噪点。
    
*   JPEG / 数据损坏 glitch：模拟压缩块损坏。
    
*   块位移 / 扫描行位移 / 像素排序：Glitch 家族。
    
*   波形 / 桶形畸变 / 像素散射：几何扭曲。
    

## 导出

*   格式：PNG、MP4（H.264）
    
*   尺寸：默认1000\*600px，无需展示选项
    
*   帧率：统一60帧，无需展示选项
    
*   质量：中、高、超高码率可选
    
*   一键复制PNG、MP4
