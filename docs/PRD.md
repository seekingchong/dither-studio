# Dither Studio PRD

## 输入与画布

### 输入类型

*   输入格式：图片（png/jpg/webp/gif 静帧/heic）与视频（mp4/webm/mov/gif 动图）。UI上不用展示说明
    
*   多媒体坑位：默认1个多媒体坑位，在全局设置中可切换为4个多媒体坑位，也就是说可以同时传4个图片/视频，且同时预览4个多媒体的dither 效果
    

### 适配方式

*   多媒体在画布内的放置：cover / contain / fill / 原尺寸，这个选项可以折叠起来，不用露出。默认 contain
    

### 画布与输出尺寸

*   画布：画布默认1000\*600px，视图支持10%、25%、50%、100%显示，默认10%
    
*   输出的最终分辨率（宽×高），独立于原图。用于社媒尺寸、印刷尺寸。
    

## 界面组织（左面板）

参数面板自上而下三层，顺序固定：

1.  **预设模块**：预设卡片、起名保存、当前方案状态。它改的是全部参数，所以常驻最上方，不从属于任何一节。
    
2.  **参数分节**：基础 / 笔画（排线专属）/ 颜色 / 影调 / 网格（抖动专属）/ 特效 / 画布。不用 tab——整栏一列、每节可折叠，默认只展开「基础」，收起的节在标题右侧显示当前值摘要。
    
3.  每节内部：一句说明 + 控件网格，低频参数收进「更多参数」折叠。
    

其中「**基础**」= 算法 + 像素化：算法族、当前族的算法、颜色模式、像素尺寸、降采样这一排（原本浮在 tab 之上的快捷参数）整排并入，后面接当前算法族自己的参数，再接网格偏移等低频项。这两件事回答的是同一个问题——一个抖动点长什么样、有多大。布局细节见 `docs/DESIGN.md` §3.1。

左栏最上方的页签是「抖动 | 排线 | 网点 | 历史」：前三个就是艺术风格（参数 `style.type`），切页签即切风格（进撤销栈，每种风格记住上次用的方案），预设模块只列当前风格的方案，「重置」退回该风格的默认方案；影调、强制背景、特效、画布三种风格共用，「颜色」在排线下只剩前景 / 背景两色，在网点下是颜色模式与网点色 / 背景色。「已微调」只看当前风格看得见的参数。

## 参数解读（Param Help）

*   每一个参数都能解释自己：鼠标停在参数标签上，弹出浮层讲清「这是什么 / 各个值什么意思 / 什么时候选它」。
    
*   选项很多的下拉（算法、调色板），属性浮层只讲整体怎么挑，逐个值的解读挂在下拉展开后的选项行上。
    
*   目标是新用户不看文档也敢动每一个滑块，老用户不必记住六十多个算法的差别。
    
*   文案是产品的一部分：写作规范与维护方式见 `docs/PARAM_HELP.md`，交互与视觉见 `docs/DESIGN.md` §3.8。
    

## 像素化 / 颗粒（Pixelation）

> 界面位置：「基础」分节。

*   像素尺寸：降采样倍率，决定颗粒粗细。1–64，默认 2–4（按输入分辨率自适应）
    
*   降低采样方法：缩小时用 box 平均 / 双线性 / Lanczos / 最近邻
    
*   网格对齐 / 偏移：像素网格相对原图的起始偏移（x, y）
    

## 影调与预处理（Tone & Pre-processing）

*   自动调整：根据dither art的特点，自动调整下方的各个参数，开关
    
*   亮度调整
    
*   对比度调整
    
*   中间调 / 高光 / 阴影调整
    
*   饱和度调整
    
*   灰度转换公式：亮度 = BT.601 / BT.709 / 平均值 / 单通道（R/G/B）/ 最大值。默认 BT.709（线性空间）
    
*   模糊：抖动前高斯模糊，压制高频细节让颗粒更"干净"。0–100 px，默认 0
    
*   锐化：与模糊相反，增强边缘，让 1-bit 输出保留结构。
    
*   去噪：面向照片的平滑滤镜
    
*   噪点：增加噪点，可选择各种类型的噪点。
    
*   边缘描边（Outline）：抖动前提取边缘叠成线条
    
*   反相：输入亮度反转。所有竞品都有。
    
*   阈值：给量化前的亮度加固定偏置，用来补偿 Bayer 整体偏亮的 bias，也是 1-bit 模式下最重要的创意滑块。
    
*   强制背景：把干净的背景换成一片规则的点，前景与高光原样保留。背景靠「与画面边缘相连的同色区域」判定（洪泛，不看亮度），所以颜色和背景一样的高光不会被当成背景；深底浅底都可以。参数：开关；点密度 0–100%（背景里带点的格子比例，默认 25，1-bit 下就是「背景亮度 = 1 − 密度」，多级时点用相邻一级）；点的明暗（自动 / 亮底暗点 / 暗底亮点）；强度 0–100%（100 完全铺平、点最规则，低一些保留原有渐变与影子）；边缘留白 0–8 格；背景色（自动取画面边缘中位色 / 手动指定）；高级：容差、渐变容差、背景范围（连通画面边缘 / 全图同色）。蒙版按像素化结果计算，替换发生在阈值偏置之后，所以点密度不随阈值滑块漂移；对 Palette / Channels 路径把背景换成同亮度的中性灰。

## 排线风格（Hatching）

> 界面位置：左栏「排线」页签。角度 / 横纵间距 / 色阶在「基础」，其余在「笔画」，前景 / 背景色在「颜色」。

一格一笔：画布按横纵间距划成格子，每格的明暗分成若干档，每档一种粗细——越暗越粗；角度、长度、圆角全图一致。相当于线网（line screen）半调，也就是素描里的排线。灰度固定在 gamma 空间取（按"看起来多亮"定粗细），不走抖动的线性光开关。

*   **角度** `hatch.angle`：0–180°，默认 45（「/」）。
*   **横向 / 纵向间距** `hatch.spacingX / spacingY`：格子宽高，3–128px，默认 14；两者不同就是长方格。像素化阶段直接按这个格子降采样，所以「像素尺寸」在排线下不出现，降采样方法与网格偏移仍共用。
*   **色阶** `hatch.levels`：2–16 档，默认 6。均分档位，直接量化（不抖动）。
*   **长度** `hatch.length`：以沿笔画方向贯穿格子的弦长为 100%，10–200%，默认 80。100% 首尾相接连成线。
*   **最粗 / 最细** `hatch.maxWidth / minWidth`：以相邻平行线的垂直间距为 100%（首尾相接的邻居不算），最暗档取最粗、最亮档取最细，中间线性；非零的至少 1px。默认 70 / 8；最细为 0 时亮部留白。
*   **圆角** `hatch.roundness`：0 方头、100 胶囊形，默认 40。渲染是圆角矩形的有符号距离场，边缘 1px 抗锯齿。
*   **交叉排线** `hatch.cross` + **交叉起点** `hatch.crossStart`：暗部再叠一层垂直方向的线，暗度过了起点才出现、到最暗档达到最粗。默认关、50%。
*   **错行** `hatch.stagger`（更多参数）：奇数行右移的比例，100 为一整格；奇数行的明暗在相邻两格之间插值。
*   **连线** `hatch.link`：无 / 沿斜线（贯穿格子的弦，45° 方格下笔画首尾接成连续线）/ 横向 / 纵向 / 横纵；**连线粗细** `hatch.linkWidth` 1–16px；**连线颜色** `hatch.linkColor`。画在笔画之下。
*   **前景色 / 背景色** `hatch.ink / paper`：笔画与纸，默认 #1C1C1C / #D9D9D9。要浅线深底就对调两色再开「反相」。

SVG 导出：每层每档一个 `<rect rx>` 定义，格子上 `<use>` 摆到笔心，连线出一条 `<path>`，是真正可编辑的笔画；格子超过 30 万报错让人调大间距。特效栈仍作用在栅格结果上，矢量版不含特效。

内置预设 9 个：Hatching（schema 默认值）、Pencil、Engraving（长度 100% + 沿斜线连线）、Crosshatch、Woodcut、Rain、Beads（横向连线）、Blueprint Lines（反相）、Brick（错行）。

## 网点风格（Halftone）

> 界面位置：「网点」页签。参考的是海报 / 丝网印那种规则网格上大小不一的圆点：每个格子采样它盖住的那块画面的平均明暗，换成一颗点的大小；点是矢量形状，边缘抗锯齿，导出 SVG 时每颗点就是一个图形。分节：基础（形状 + 网格）/ 网点（大小与融合）/ 颜色 / 影调 / 特效。

*   **基础 = 形状 + 网格（`halftone.shape` + `screen.*`）**
    
    *   网点形状：圆形 / 方形 / 圆角方 / 菱形 / 三角 / 六边形 / 线条 / 十字。每种形状都按「100% 时刚好放进自己的格子」定义，形状跟着网格角度转。
        
    *   横向间距 / 纵向间距：相邻点的中心距，也是格子的宽 / 高，3–96px，默认 12；两者不同就是长方形格子。网点粗细由它决定，网点大小只是格子里的占比。
        
    *   网格角度：0–180°，默认 0；45 是传统印刷网线角度。网格绕画布中心转，画布中心永远是一颗点的中心。
        
    *   排列：方格 / 交错（隔行错开半格，像蜂窝）。
        
    *   偏移 X / Y（高级）：网格挪动，让某个细节落在点的中心。
        
*   **网点（`halftone.*`）**
    
    *   网点大小：最暗处的点占格子多大，10–150%，默认 100；超过 100 相邻的点连成片。
        
    *   最小网点：最亮处也保留多大的点，0–100%，默认 10——留一点，背景就是一层细密的点阵（参考图那种）。
        
    *   网点响应：面积正比（点的面积与墨量成正比，灰度最准，印刷的做法）/ 直径正比（更图形化）。
        
    *   网点增益：中间调整体放大或缩小，−100 到 100，印刷里的 dot gain。
        
    *   灰阶分级：开关 + 级数 2–32（默认 6），把点的大小限定在固定几档，海报感。最小网点算一档。
        
    *   点融合：0–100%，相邻的点像液体一样粘连。实现是距离场的多项式 smooth-min，只在两个点靠得比融合半径近时长桥，单独的小点大小不变（模糊 + 阈值那种做法会把小点吃掉）。
        
    *   平滑边缘（高级）：抗锯齿开关，关掉只剩网点色与背景色两种颜色。
        
*   **颜色（`ink.*`）**
    
    *   颜色模式：双色（网点色 + 背景色）/ 原图色（每颗点取原图那一块的颜色）/ CMYK 分色（青品黄黑四层网点，各自按 15° / 75° / 0° / 45° 加网格角度叠印，正片叠底）。
        
    *   网点颜色（双色）、背景色。亮点配深底：把两色对调再打开影调里的反相。
        
*   **影调**：与抖动同一套。线性空间开关对网点有效（面积正比在线性光里算墨量）；强制背景在网点下把背景换成大小均匀的点。
    
*   **画布、特效**：共用。像素化的方法与偏移在网点下不出现——网点自己按网格间距缩小画面采样。
    
*   **导出**：PNG / 视频与抖动相同；SVG 是真矢量——`<circle>` / `<rect>` / `<polygon>`，网格旋转写在 `<g transform>` 上，CMYK 四组 `mix-blend-mode: multiply`，点融合用高斯模糊 + alpha 对比滤镜近似并把原形状叠回去，特效栈不进 SVG，网点多于 30 万个报错让人调大间距。
    
*   **预设**：默认、Poster（海报红圆点分 8 档）、Newsprint（45° 细圆点报纸）、Comic（Ben-Day 四档）、CMYK Print、Ink Blob（大圆点带融合）、Line Screen（线网雕刻）、Mosaic（圆角方六档）、Triangles（交错三角亮点配深底）、Color Dots（原图色交错灯珠）、Honeycomb（六边形蜂窝）。用户预设同抖动。
    

## 颜色与调色板（Color & Palette）

### 颜色模式

*   沿用彩色化调研的四条路线：Palette（A）、Tint（B）、Channels（C）、Accent 叠加层（D）。
    
*   颜色模式：单色（1-bit 黑白）/ 灰阶 / Tint（双色 / 色带映射）/ Palette（真彩量化）/ Channels（RGB 或 CMYK 分通道）。Dither Garden 叫 Monochrome / Duotone / Tritone / RGB；fuegocoding 叫 Duotone / Grayscale / Custom Palette / Original。默认 Tint（黑白双色，即 1-bit）
    
*   颜色深度（灰阶级数） ：量化级数 / 调色板色数。灰阶模式下 2–16 级；Palette 模式下 = 调色板色数。
    
*   深度 / 色数错配：先按 N 级亮度抖动，再映射到 M 色调色板，N ≠ M 时产生 color glitch。开关
    

### 调色板

*   预设调色板：Game Boy（原版/Pocket）、CGA 0/1、EGA、C64、ZX Spectrum、NES、PICO-8、DB16/DB32、Apple II、Mac 1-bit、Web Safe、灰阶 4/8/16；
    

### Tint / 色带映射（Tint 模式专属）

*   暗色 / 亮色：双色调的两个颜色选择器。
    
*   色带（gradient map）：N 级灰 → N 色 ramp，可加中间色站点。
    

### Accent 强调色层（叠加层）

*   开关 + 强调色板：1–6 色，每色带权重。
    
*   密度：被替换像素比例。
    
*   放置规则：随机 / 蓝噪声 / 仅某灰阶档 / 误差溢出 / 边缘。
    
*   目标范围：仅前景 / 仅背景 / 全部。
    
*   最小间距 / 连锁概率 / 种子：防扎堆、偶发短线、复现。
    

## 后处理特效（Effects，可堆叠）

*   扫描线 / CRT：横向暗线 + 可选桶形畸变、荧光点。
    
*   胶片颗粒：抖动后叠噪点。
    
*   JPEG / 数据损坏 glitch：模拟压缩块损坏。
    
*   块位移 / 扫描行位移 / 像素排序：Glitch 家族。
    
*   波形 / 桶形畸变 / 像素散射：几何扭曲。
    

## 导出

*   格式：PNG、MP4（H.264）
    
*   尺寸：默认1000\*600px，无需展示选项
    
*   帧率：统一60帧，无需展示选项
    
*   质量：中、高、超高码率可选
    
*   一键复制PNG、MP4
